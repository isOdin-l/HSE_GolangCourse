# Лабораторная работа 2

`internal/queries` - SQL-слой. Нужен как ещё одна абстракция между слоем репозитория и инфраструктурой, на которой будет выполняться запросы. Построение запросов через squirrel

Repository слой зависит только от собственных неэкспортируемых интерфейсов

Это нужно, если нам понадобиться добавить кеш или изменить библиотеку/бд. Тогда мы просто меняем их в queries, а слой репозитория не троегается

Т.е
Бизнес логика даёт атомарные задачи
Репозиторий использует доступные инструменты
Queries выполняет запросы
Infra предоставляет доступ до БД, кешей, брокеров и т.д
